
# KEY-MOUSE

마우스 오토 클릭 프로그램

## Features

- 특정 위치 클릭
- 마우스 위치 캡쳐
- 지정된 cps로 지정된 총 클릭 수 만큼 동작
- ESC키로 비상 정지
- 매우 세련된 UI
